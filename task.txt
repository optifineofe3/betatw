Два бага после последнего фикса. Не ломай то, что уже работает (нет краша, DEL в целом ок, кнопка сохранения ок).

### Баг 1. На удалённых сообщениях появляется лишний EDITED
Если человек удаляет сообщение, рядом с DEL появляется ещё и EDITED — хотя сообщение никто не редактировал.

Нужно:
- DELETED и EDITED определять независимо
- revoked/deleted сообщение НЕ должно автоматически считаться edited
- если isDel == YES, не ставить isEdit просто так
- убрать false positive EDITED на удаленных сообщениях

### Баг 2. История правок не сохраняет original
При реальном редактировании:
- по нажатию на EDITED показывается только текущий текст
- original пишет: "Original message text was not captured during this session"

Нужно:
- ДО правки обязательно кэшировать исходный текст сообщения
- при первой правке в цепочке должен быть:
  1) Original message (старый текст)
  2) Current edited message (новый текст)
- при следующих правках:
  Original → Edit 1 → Edit 2 → ... → Current
- текст original не должен теряться
- timestamps по возможности сохранять

Где чинить:
- кэш original text должен писаться ДО edit (например при обычном layout/появлении сообщения, или в хуках до apply edit)
- запись edit chain должна происходить в хуках редактирования (attachMessageEdit / applyOutgoingEdit и т.п.), а не ломаться из-за облегчённого layoutSubviews
- layoutSubviews оставь лёгким, но данные для original/edit history должны успевать сохраняться

### Важно
- не возвращай краш на edited сообщениях
- не ломай DEL
- не ломай MediaSaver
- сделай точечный фикс

Цель:
1) на deleted только DEL, без ложного EDITED
2) на edited по тапу видна нормальная история, где original — реальный старый текст, а не заглушка
